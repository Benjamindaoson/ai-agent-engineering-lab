## ADDED Requirements

### Requirement: Present a real Agent engineering handoff
The home view SHALL state that a user can take over a real Agent project, change code, and prove the business result. It SHALL provide an entry action for the first project and a secondary action for recorded run evidence.

#### Scenario: User opens the home view
- **WHEN** the application opens on the home route
- **THEN** the primary viewport SHALL identify the Browser Agent repair project and expose both project-entry and real-run-record actions

### Requirement: Use one restrained product visual language
The application SHALL use shared tokens and reusable control, panel, code, and evidence treatments across home, trial, workspace, result, delivery, and replay views.

#### Scenario: User moves between product views
- **WHEN** the user enters a project or opens a result, delivery, or replay view
- **THEN** typography, action controls, focus treatment, panel boundaries, and status colors SHALL remain visually consistent
