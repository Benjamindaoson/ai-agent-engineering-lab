# 轻量满分版设计

## 目标

在不引入数据库、Web 服务、队列或复杂框架的前提下，把项目从“固定示例可运行”提升为“可复用、可评测、失败可解释”的单机 CLI 原型。

## 设计

- 输入由 `inputs.json` 或命令行参数提供；未提供时保留默认示例。
- 每次运行接收独立 `output_dir`，运行前只清理本项目已知输出文件，避免旧结果污染。
- `MarketingPostsCrew` 接收输出目录；现有 6-task 顺序和 Pydantic 输出契约保持不变。
- LLM 和 Serper 只增加有限重试；重试耗尽后抛出明确错误，不伪装成成功。
- 研究任务要求输出来源名称、URL、日期和证据等级；评测检查来源可追溯性。
- `cases.json` 的每个案例都生成独立目录并独立评测；不再重复检查同一份全局输出。
- 测试使用 Python 标准库 `unittest`，不新增测试依赖。

## 非目标

- 不做 Web UI、数据库、登录、后台任务、部署系统或多租户。
- 不重写现有 CrewAI Agent/Task 业务流程。

## 验收标准

1. `uv run marketing_posts` 仍可运行。
2. `uv run marketing_posts --input inputs.example.json --output-dir output/custom` 可写入独立目录。
3. 运行前旧的已知输出不会被复用。
4. 三个评测案例拥有各自输出目录并分别通过结构、内容和来源检查。
5. 缺少必填输入、API Key 或外部调用最终失败时，命令返回非零并输出明确原因。
6. 编译、标准库测试和评测全部通过。
