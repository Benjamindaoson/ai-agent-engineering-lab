# 教学注释：python-ai-alibaba-demo

这一关讲 Alibaba / Spring AI Alibaba 相关能力在 Python 里的教学对照。

## 这一关学什么

- Markdown 文档解析
- PDF 占位解析
- Baidu 搜索请求形状
- Chat 工具调用
- 文件 RAG
- provider 配置

## 先看哪些文件

1. `python_ai_alibaba_demo/chat_controller.py`：Chat 和工具调用入口。
2. `python_ai_alibaba_demo/markdown_test.py`：Markdown 解析。
3. `python_ai_alibaba_demo/pdf_test.py`：PDF 离线替身。
4. `python_ai_alibaba_demo/baidu_test.py`：搜索请求形状。
5. `python_ai_alibaba_demo/offline_demo.py`：课堂离线演示入口。

## 课堂讲法

这里很多能力真实环境依赖云服务，课堂先讲请求结构和离线替身，不强求现场联网。
