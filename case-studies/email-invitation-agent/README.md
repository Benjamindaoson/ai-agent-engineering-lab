# 邮件邀请 Agent

这是一个轻量邮件邀请生成 Agent，用于演示如何用 Python 项目结构封装邮件撰写和邀请任务。

## 项目定位

这是从 `D:\01_项目\04_资料参考` 中整理出来的私有 GitHub 快照。保留它的目的，是防止本地唯一代码、课程改动、Prompt、Agent 工作流和项目结构丢失。

## 当前状态

- 这是资料参考区中的项目快照，不一定是生产级项目。
- README 已统一改为中文。
- 如果项目来自第三方仓库，本仓库只保存本地学习和改动快照，不覆盖原作者仓库。
- 如果项目是本地唯一目录，本仓库作为备份和后续整理入口。
