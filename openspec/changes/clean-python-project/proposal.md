# Clean Python Project

## Why

The Python workspace contains gigabytes of local dependencies, caches, build output, tool metadata, and obsolete demo files. These obscure the maintained source and make the repository unsuitable for publishing.

## What Changes

- Remove approved generated and tool-specific content.
- Add a one-command PowerShell setup and local AgentLab launcher.
- Document clean setup and verify the project from a dependency-free state.

## Out of Scope

- Refactoring course or AgentLab business logic.
- Removing maintained course, product, test, or planning content.
