AgentLab Live Recovery 正式验证

我们模拟了一个生产系统中很常见的问题：Agent 提交采购申请后，网页告诉它已经成功，但后台第一次实际上没有保存这张采购申请。

原来的系统相信页面和 Agent 自己的完成判断，所以会把一个没有真正办成的任务当成成功。修复后的系统会进一步检查真实数据库；如果采购申请没有真正存在，就让同一个 Agent 在原来的浏览器里继续工作，并在每次继续以后重新检查业务结果。

模型：deepseek/deepseek-v4-flash；基础设施错误：0。
