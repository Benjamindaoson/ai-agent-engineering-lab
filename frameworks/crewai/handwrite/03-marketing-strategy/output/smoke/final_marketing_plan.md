# 「道生AI」AI Agent 实战训练营2026营销方案

---

## 一、项目概述

「道生AI」面向开发者推出 **「从原理到工程交付」的 AI Agent 深度实战课程**，填补当前市场“调包侠”与“玩具项目”之间的空白。课程覆盖初级、中高级及职业转型开发者，通过分层教学、免费引流、社群运营等组合策略，在2026年第一季度实现首期训练营报名100人以上，同时建立品牌技术口碑与私域流量池。

---

## 二、市场研究

### 2.1 行业背景
- AI Agent 成为大模型落地核心载体，企业招聘 Agent 开发工程师需求同比增长 200%，但市场上成熟人才极度稀缺。
- 现有培训多为“API 调包”或“理论科普”，极少涉及手写框架、工程部署、可复用代码交付，导致学员“学了不会用”。
- 开发者学习路径不清晰：新手盲目跟风框架，进阶者缺乏系统性工程方法论。道生AI 以 **“原理穿透 + 工程硬实力”** 直接切入该断层。

### 2.2 用户痛点调研
- **初级开发者（1-3年）**：只会调用 LangChain 等高层次库，遇到自定义需求束手无策。
- **中高级开发者（3-8年）**：了解概念但难以从零构建可上线的 Agent 系统，缺乏工程化思维。
- **职业转型者**：非 CS 背景，需要一条从基础到交付的完整学习路径。

### 2.3 市场机会
- 免费技术内容（知乎/B站/CSDN）仍为开发者获取信息的主要渠道，内容引流成本低、转化率高。
- 低价付费产品（29.9元面试冲刺包）可快速筛选高意向用户，同时通过裂变实现低成本获客。

## 四、竞争分析

### 4.1 现有竞品特征

| 竞品类型 | 代表 | 优势 | 弱点 |
|----------|------|------|------|
| 大厂官方培训 | 百度AI Studio、阿里云培训 | 品牌信任度；免费资源多 | 内容偏理论、泛化；无深度手写课程 |
| 技术社区课程 | 知乎、CSDN 专栏 | 价格低；碎片化 | 缺乏系统性和工程交付；无老师答疑 |
| 个人/小团队课程 | 各类知识星球、小报童 | 价格灵活；社群氛围好 | 内容质量参差；无持续更新；无法构建完整知识体系 |

### 4.2 道生AI 差异化优势
- **从原理到手写**：不依赖 LangChain 等黑盒框架，逐行实现 ReAct 等核心模式。
- **工程化交付**：学员结课后可带走可直接部署的 Agent 系统代码（含 Docker 化、API 封装、错误恢复）。
- **教师亲自答疑**：每周直播答疑，讲师为一线 AI 架构师，非助教代劳。
- **分层设计**：低门槛免费直播 → 29.9 元冲刺包 → 进阶付费，降低决策心理门槛。
