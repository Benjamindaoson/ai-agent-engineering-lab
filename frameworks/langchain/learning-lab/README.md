# LangChain Learning Lab

Consolidated from the former private repository `project-collection-langchain-learning-lab`.

This directory preserves the useful learning examples while dropping IDE metadata, lockfiles, and machine-specific project files.

Included examples:

- `basic_agent.py` — minimal LangChain-style agent usage;
- `research_agent.py` — research-agent workflow;
- `deep_research_agent.py` — deeper research workflow;
- `memory_test.py` — memory behavior experiment;
- `memory_restart_test.py` — restart/persistence experiment.

This is a **teaching/reference asset** inside AI Agent Engineering Lab, not a separate flagship project.

New teaching work should follow the conventions of the canonical `ai-agent-engineering-lab` repository.
