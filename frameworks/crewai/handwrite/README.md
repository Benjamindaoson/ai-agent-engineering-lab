# CrewAI-Handwrite

CrewAI 手写练习项目合集。

## 项目用途

该目录用于保存多个 CrewAI 教学、练习和实验项目，重点是多智能体协作、任务拆解、Markdown 校验、游戏构建和营销策略生成。

## 子项目

```text
01-game-builder-crew          游戏构建 Crew 示例
01-project-task-manager-crew  项目任务管理 Crew 示例，已单独上传到 GitHub
02-markdown-validator         Markdown 校验 Crew 示例
03-marketing-strategy         营销策略生成 Crew 示例
markdown_validator            简化版 Markdown 校验示例
marketing_strategy            简化版营销策略示例
output                        运行输出样例
```

## 上传边界

源码、README、配置模板、锁文件和输出样例可以上传。

不上传：

- `.venv/`
- `.env`
- 缓存目录
- 临时文件
- 子项目内部 `.git`

## 当前状态

这是未完成开发中的 CrewAI 实验合集。适合作为学习、复用 Agent 工作流和 Prompt 结构的资料库，不作为单一生产项目维护。
