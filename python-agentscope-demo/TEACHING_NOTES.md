# 教学注释：python-agentscope-demo

这一关是 AgentScope 生态总览，用来对比同一套 Agent 思想在不同框架里的表达。

## 这一关学什么

- 基础 Agent
- 工具调用
- Memory
- Hook
- Human-in-the-loop
- Pipeline
- RAG
- MCP
- Vision
- Studio 入口

## 先看哪些文件

1. `python_agentscope_demo/hello_world_demo.py`：最小 Agent。
2. `python_agentscope_demo/tool_demo.py`：工具调用。
3. `python_agentscope_demo/short_memory_demo.py`：短期记忆。
4. `python_agentscope_demo/sequential_pipeline_demo.py`：顺序流水线。
5. `python_agentscope_demo/offline_demo.py`：课堂离线演示入口。

## 课堂讲法

这个项目内容多，课堂不要全讲。建议只选五条主线：基础 Agent、工具、记忆、Pipeline、生态入口。
