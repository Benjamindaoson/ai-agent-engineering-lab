## ADDED Requirements

### Requirement: Maintain product behavior through visual redesign
The visual redesign SHALL preserve the existing session creation, trial submission, workspace editing, run start and polling, cancellation, delivery, mentor, screenshot, and replay actions.

#### Scenario: User starts a project from redesigned home
- **WHEN** the user selects the primary start action
- **THEN** the product SHALL create a session and display the existing trial flow without an API contract change
