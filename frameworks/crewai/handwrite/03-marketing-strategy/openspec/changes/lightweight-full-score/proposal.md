# 轻量满分版

## Why

当前项目能生成结果，但输入写死、评测案例未真正隔离、旧输出可能污染结果，且研究来源不可审计。需要补齐这些产品化基础，同时保持单机 CLI 的轻量边界。

## What Changes

- 增加统一输入加载与必填字段校验。
- CLI 增加 `--input` 和 `--output-dir`。
- Crew 输出目录改为实例级配置，并清理已知旧输出。
- 增加轻量 LLM/Serper 重试和失败传播。
- 研究输出增加来源 URL/日期/证据等级要求。
- 评测案例独立运行、独立输出、独立检查。
- 增加标准库运行时测试和示例输入文件。

## Non-goals

- 不增加数据库、Web 服务、队列、认证或新的运行时依赖。
