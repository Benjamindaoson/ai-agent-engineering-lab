# TOOLS.md - 本地笔记

技能（Skills）定义了工具如何工作。这个文件用于记录你的特有配置 —— 那些你独有设置的内容。

## 这里放什么

例如：

- 摄像头名称和位置
- SSH 主机名和别名
- TTS（文本转语音）的首选声音
- 扬声器/房间名称
- 设备昵称
- 任何特定于环境的信息

## 示例

```markdown
### 摄像头

- living-room → 主区域，180°广角
- front-door → 入口处，运动触发

### SSH

- home-server → 192.168.1.100, 用户：admin

### TTS

- 首选声音："Nova"（温暖，略带英式口音）
- 默认扬声器：厨房的 HomePod
```

## 为什么要分开

技能是共享的，你的设置是你自己的。分开存储意味着你可以更新技能而不会丢失你的笔记，也可以分享技能而不会泄露你的基础设施。
