# 评测说明

`evals/` 是营销策略项目的轻量规则评测目录，用来检查生成结果是否完整、格式是否可解析、内容是否存在明显问题。

## 运行

先生成案例输出：

```powershell
uv run python evals/generate_cases.py
```

再运行评测：

```powershell
uv run python evals/run_eval.py
```

## 检查项

- 是否生成最终 Markdown 文件；
- 是否生成 5 个营销活动；
- 活动是否包含名称、描述、受众和渠道；
- 是否包含 KPI；
- 是否包含预算建议；
- 是否包含行动号召；
- JSON 文件是否可解析；
- 是否存在明显夸大承诺；
- 活动内容是否高度重复；
- 是否误写固定年份或明显拼写错误。

## 当前定位

这是低成本质量门，不是完整自动化评测平台。
