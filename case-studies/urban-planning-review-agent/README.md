# 城市控规审查辅助 Agent

这是一个面向中国城市规划审查场景的 RAG + 多智能体原型。项目以成都控规局部调整审查为示例，用大模型、向量检索和多 Agent 协作来辅助提取规划调整内容、匹配审查规则，并生成结构化审查意见。

## 解决的问题

传统控规审查通常需要人工阅读几十页材料，再结合历史案例、政策规则和专业经验判断是否合规。这个过程耗时长、容易漏项，也难以沉淀可复用的审查知识。

本项目尝试把审查流程拆成三个环节：

1. 页面扫描 Agent：读取规划调整报告，提取实质性调整内容；
2. RAG 检索模块：从本地知识库中检索相关政策、规则和历史案例；
3. 报告生成 Agent：生成接近正式审查意见格式的结构化文本。

## 环境变量

代码中的真实 API Key 已替换为环境变量占位符。运行前需要在本地配置：

```env
DEEPSEEK_API_KEY=你的_API_Key
```

不要把真实 Key 写入代码或提交到 GitHub。
