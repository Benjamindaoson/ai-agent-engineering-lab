技术内核是：

> **Claude Agent SDK 驱动的项目级评测与证据生成引擎。**

更完整一点：

```text
Claude Agent SDK
+ Sandbox
+ Rubric Engine
+ Evidence Engine
```

这是 AgentLab 的技术内核。

它负责把学员提交的项目变成可评测、可追踪、可证明的能力证据。

核心技术闭环是：

```text
Submission
→ Sandbox 工程检查
→ Claude Agent SDK Repo / Code / RAG / Workflow Review
→ Rubric Scoring
→ Structured Review JSON
→ Evidence Item
→ Skill Score Update
→ Hiring Passport Snapshot
```

其中各部分职责是：

```text
Claude Agent SDK：
读 Repo、看代码、运行有限命令、分析项目、生成评审。

Sandbox：
隔离运行学员代码，做安装、启动、测试、Demo 检查。

Rubric Engine：
把项目评审映射到岗位能力标准和评分规则。

Evidence Engine：
把评审结果转成结构化能力证据。

Skill / Passport Engine：
把证据聚合成能力图谱和 Hiring Passport。
```

所以如果一定要选一个“技术内核”，就是：

> **Claude Agent SDK + Sandbox + Evidence Pipeline。**

不是单独 Claude Agent SDK。
Claude Agent SDK 是智能执行核心，Sandbox 是安全执行核心，Evidence Pipeline 是产品数据核心。
