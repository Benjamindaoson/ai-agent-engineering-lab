# 教学注释：python-spring-ai-demo

这一关用于把 Java Spring AI 的概念翻译成 Python 版本，方便 Java 学员迁移理解。

## 这一关学什么

- Chat
- System Prompt
- Memory
- RAG
- Tool Calling
- MCP 概念

## 先看哪些文件

1. `python_spring_ai_demo/zhouyu_controller.py`：Chat、Memory、RAG 对照。
2. `python_spring_ai_demo/tool_controller.py`：工具调用对照。
3. `python_spring_ai_demo/mcp_controller.py`：MCP 概念对照。
4. `python_spring_ai_demo/cosine_similarity.py`：向量相似度的最小实现。
5. `python_spring_ai_demo/offline_demo.py`：课堂离线演示入口。

## 课堂讲法

不要把它讲成一个新框架。它是“Spring AI 概念在 Python 里怎么表达”的对照课。
