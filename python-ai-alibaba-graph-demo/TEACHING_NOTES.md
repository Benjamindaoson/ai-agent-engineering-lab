# 教学注释：python-ai-alibaba-graph-demo

这一关讲图工作流。复杂 Agent 不一定是一条直线，也可以是节点和边组成的图。

## 这一关学什么

- 节点
- 边
- 条件分支
- 中断与恢复
- Memory Saver
- 子图和并行结构

## 先看哪些文件

1. `python_ai_alibaba_graph_demo/graph_application.py`：图工作流主入口。
2. `python_ai_alibaba_graph_demo/graph_config.py`：图如何配置。
3. `python_ai_alibaba_graph_demo/blog/title_node_action.py`：标题节点。
4. `python_ai_alibaba_graph_demo/blog/content_node_action.py`：内容节点。
5. `python_ai_alibaba_graph_demo/offline_demo.py`：课堂离线演示入口。

## 课堂讲法

这一关适合画图讲。让学生看到：复杂任务可以拆成节点，每个节点只负责一小步。
