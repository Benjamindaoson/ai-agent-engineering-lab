# 教学注释：python-agentscope-a2a-demo

这一关讲 AgentScope 生态里的 A2A 表达，和 `python-a2a-demo` 形成对照。

## 这一关学什么

- AgentCard
- Skill 声明
- 天气工具
- 生成任务流
- 客户端发现和流式响应

## 先看哪些文件

1. `python_agentscope_a2a_demo/a2a_server_spring_boot_application.py`：服务端入口。
2. `python_agentscope_a2a_demo/a2a_client_application.py`：客户端入口。
3. `python_agentscope_a2a_demo/weather_service.py`：天气服务。
4. `python_agentscope_a2a_demo/offline_demo.py`：课堂离线演示入口。

## 课堂讲法

先讲第 11 关 `python-a2a-demo`，再讲这一关。让学生看到：协议思想可以被不同生态实现。
