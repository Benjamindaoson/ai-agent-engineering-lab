# 中国大陆中文市场研究报告：AI Agent 实战培训赛道

**报告日期**：2025年7月
**研究对象**：面向开发者和职业转型者的 AI Agent 项目实战课程（以“从零手写、调试、工作流设计和工程化交付”为核心卖点）
**委托方提及品牌**：道生AI

---

## 执行摘要

本报告围绕“面向开发者和职业转型者的 AI Agent 项目实战课程”这一产品定位，对中国大陆中文市场的行业现状、市场趋势、目标客户需求、竞争格局、机会与风险进行了调研。报告严格区分已验证事实、合理推断和暂无足够证据的信息，并附来源表。

**核心发现**：

1. **“道生AI”品牌身份不明**：在公开互联网搜索中，未找到名为“道生AI”的独立培训品牌或公司主体。搜索结果中的“道生”主要指向腾讯集团高级执行副总裁汤道生先生，与委托方描述的课程无关。
2. **市场处于爆发期**：中国 AI Agent 市场在2025年进入高速增长阶段，市场规模达182.34亿元（同比+78.03%），带动了相关培训需求的激增。
3. **竞争格局已初步形成**：极客时间、路飞学城、CSDN等平台已推出类似课程，定价在 ¥98–¥6999 之间。
4. **“从零手写+工程化”定位存在差异化空间**：多数竞品侧重工具链使用（LangChain/Dify）或低代码平台，强调手写代码和工程化交付的课程相对稀缺。

## 2. 市场趋势

### 2.1 已验证的趋势信息

- **技术范式切换**：行业共识认为 AI 应用范式正从 Chatbot 向 AI Agent 跃迁。腾讯汤道生（2026年3月公开演讲）、IBM 翟峰（2025年5月）等多位行业领袖均表达了类似判断。经交叉验证，此趋势可视为已验证事实。

- **企业级 Agent 需求上升**：亿欧智库《2025中国AI Agent商业应用场景洞察研究》指出，AI Agent 从“实验室”走向“生产线”，企业期望 AI 角色从“助手”升级为“员工”。

- **招聘市场信号**：CSDN/ModelEngine社区报道称，2025年Q2中国软件市场中“AI Agent”“多模态模型”“模型部署”为三大核心增长引擎，相关岗位需求持续上升。

### 2.2 合理推断的趋势

- **培训课程将从“概念普及”向“工程化交付”演进**。基于行业从讨论“什么是Agent”转向“如何生产级部署Agent”，课程内容侧重点必然随之迁移。

- **“手写代码”能力将重新受到重视**。当前大量课程依赖低代码/无代码平台（Coze、Dify等），但企业级部署通常需要深度定制能力，具备手写 Agent 框架能力的开发者将更受青睐。

### 2.3 暂无足够证据的信息

- “AI Agent 工程师”作为一个独立职业岗位的薪资中位数和岗位数量——目前缺乏来自权威招聘平台的系统性统计数据。
- 企业在 AI Agent 培训方面的年度预算——无公开数据。

## 6. 市场机会

### 6.1 已验证的机会

1. **市场高速增长**：中国 AI Agent 市场年增长率 78%，人才供给远跟不上需求，培训市场水涨船高。
2. **企业预算充足**：各云厂商和企业都在积极布局 AI Agent，培训预算有保障。
3. **用户付费意愿强**：多位课程运营者反馈，开发者群体对职业转型类课程的付费意愿较高（Reddit讨论、极客时间课程销量）。

### 6.2 合理推断的机会

1. **“从零手写”空白地带**：市面上多数课程依赖现成框架（LangChain、Dify、Coze），强调“手写 Agent”的课程较少，存在差异化空间。
2. **工程化交付能力稀缺**：企业需要的不仅是“会搭Agent”的人，更是“能上线、能运维、能优化”的工程师。以此定位的课程能切中企业真实需求。
3. **职业转型市场刚需**：大量传统开发者（Java、PHP、.NET等）面临 AI 冲击，转型 Agent 开发成为刚需。这类人群付费意愿和客单价较高。

### 6.3 暂无足够证据的机会

- **校企合作渠道**：是否有高校开设 AI Agent 课程，合作空间如何——暂无公开数据。

## 7. 潜在风险

### 7.1 已验证的风险

| 风险 | 说明 | 证据 |
|------|------|------|
| 竞争加剧 | 极客时间、路飞学城等头部机构已进入，市场快速拥挤 | 多来源交叉验证 |
| 技术迭代快 | LLM框架和工具更新频繁，课程内容可能快速过时 | 知乎、CSDN社区广泛讨论 |
| 免费资源冲击 | Hugging Face、吴恩达、微软等提供高质量免费课程 | 已验证多个免费课程存在 |

### 7.2 合理推断的风险

1. **品牌认知度建设困难**：如果“道生AI”是一个新品牌，在巨头环伺下建立信任需要时间和大量投入。
2. **定价压力**：免费/低价优质资源（¥98-¥299 的极客时间课程）会对高价课程（¥4000+）形成价格锚定。
3. **效果验证难度**：培训效果（学员就业率、薪资涨幅）难以量化验证，容易引发用户信任危机。
4. **师资壁垒**：能同时具备“大厂工程实战经验”和“教学能力”的讲师稀缺。

### 7.3 暂无足够证据的风险

- **政策监管风险**：AI 培训是否需要特定资质或许可——目前未找到相关政策规定。
- **AI Agent 赛道是否会出现泡沫**：如果市场降温，培训需求可能同步萎缩——暂无权威预测。
